# Movie Recommendation Model
## Based on User Ratings
### 1. Problem Statement
Most people decide on what movie to watch based on user ratings.
It is important for movie directors to know which movies are liked most for them to make better movies.
This leads to more movie views, happier customers and directors getting a higher profit.

### 2. Project Description
The aim of this project is to build a movie recommendation model based on collaborative filtering./n
The model tries to predict the rating a user would give to a movie they haven’t rated yet./n
I will be using a popular movie dataset from Kaggle website with several CSV files namely:Movies, Links, Ratings and Tags./n
My feature variables are movieId and userId./n
My target variable is ratings./n
