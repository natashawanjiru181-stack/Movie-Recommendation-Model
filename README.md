Overview of my dataset
This project uses popular movies dataset-9742 movies found in kaggle website. 
Last updated three years ago by Aman Chauhan since being loaded to my Jupyter Notebook.
The dataset contains 4 CSV files namely:Links, Movies, Ratings and Tags.
Each file contains the following:
- `movies.csv`: Movie titles and genres
- `ratings.csv`: User ratings for movies
- `tags.csv`: User-generated tags for movies
- `links.csv`: External IDs for IMDb and TMDB
The feature variables are movieId, userId, tmbId, title and timestamp.
The target variables are ratings and genres.
The goal of the project is to build a simple recommendation system based on user ratings and genres.
